Notre histoire

Un rêve d'enfance devenu serveur

True Vanilla est né d'un rêve d'enfance : celui d'avoir un jour un serveur Minecraft le plus Vanilla possible, pour que les joueurs puissent avoir un endroit où jouer sans avoir à se prendre la tête avec des wikis, ou des commandes.

Ce rêve est devenu réalité, avec une promesse simple : rester aussi proche que possible de l'expérience vanilla de Minecraft, tout en ajoutant les fonctionnalités de confort qui rendent la vie sur un serveur agréable.

  • 90% Vanilla. Pas de kits, pas de crates P2W. TOUT s'obtient en jouant.
  • Commandes de base. Téléportations, homes, RTP. Que du QOL.
  • Aucun, et jamais de P2W. La boutique finance le serveur, elle n'achète pas la victoire.
Simple Voice Chat intégré - parlez de vive voix aux joueurs autour de vous. Totalement optionnel.

Prêt à nous rejoindre ?

Rejoindre True Vanilla

Version 1.21.8

  1. Rejoignez notre Discord

    Votre compte Discord doit être lié à votre compte Minecraft pour jouer. Le lien est sur la page À propos.

  2. Ajoutez le serveur dans Minecraft

    Minecraft Java 1.21.8 → Multijoueur → Ajouter un serveur → adresse : play.true-vanilla.fr

  3. Connectez-vous une première fois

    Le serveur vous donne un code de liaison à 4 chiffres puis vous déconnecte. C'est normal !

  4. Liez votre compte sur Discord

    Envoyez ce code en message privé au bot du serveur Discord nommé "True Vanilla S5".

  5. Reconnectez-vous et jouez !

    Une fois votre compte lié, vous pourrez jouer ! Pensez au mod Simple Voice Chat (optionnel) pour parler aux joueurs autour de vous.
